# Maison Rétro

Three analogue instruments in one React app:

- **I · The Writing Desk** — a typewriter. Type with your keyboard (or click the keys), Return for a new line, pick a stamp from the drawer and press it onto the sheet, then *Pull & Print* to print or save it as an image.
- **II · The Listening Room** — a cassette deck. REC up to 1 minute, PLAY to hear it back as worn tape (warmth, hiss, wow & flutter, age dials). *Keep* downloads a .wav.
- **III · The Darkroom** — an instant camera. Live view in the lens, red shutter (or Space), the print ejects and develops, then drag it around the table, caption it and save it.

## Run

```bash
npm install
npm run dev
```

Open the printed URL (camera + microphone need `localhost` or https). Sound on.
